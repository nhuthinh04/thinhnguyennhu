This project was conducted at Project XYaZ Lab, HUST, focusing on modeling and simulating the dynamics of a 3-RRR planar parallel robot using MATLAB and Simulink.

### Key Highlights
- **Kinematic & Dynamic Modeling:** Derived forward and inverse kinematics using vector loop closures and derived closed-form dynamic equations via Lagrange and Newton-Euler formulations.
- **Simulation in MATLAB/Simulink:** Implemented comprehensive multi-body simulation to analyze joint torque requirements, singularity zones, and operational workspace.
- **Trajectory Tracking Control:** Designed and evaluated feedforward plus feedback control strategies (Computed Torque Control / PID) for high-precision end-effector trajectory following.
